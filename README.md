# 智肺呼吸 (RespiCare 360) 
## 慢阻肺数字化智慧管理与知识图谱协同平台

---

## 1. 项目简介与全新定位

**智肺呼吸 (RespiCare 360)** 是一套基于 **GOLD 2024 (全球慢性阻塞性肺疾病倡议)** 最新临床指南规范构建的现代化数字慢病全病程协同管理平台。

针对原先单一移动端的局限，本项目全面重构为 **“电脑桌面宽屏 (PC 端) + 手机移动端 (Mobile 端)” 全场景自适应架构**：
- **桌面宽屏环境 (≥ 1024px)**：呈现专业临床三栏复合工作台、慢病综合质控驾驶舱、NVL/ECharts 大幅时序图谱分析拓扑。
- **移动便携环境 (< 768px)**：呈现流式微质感卡片、金刚区 9+ 功能快捷入口、触控优化与固定底部 4-Tab 导航。
- **仿真视口切换**：PC 端顶部控制台内置“📱 手机视口”与“🖥️ 全景模式”一键切换器，方便临床教学、路演汇报与设备联调。

## 2. 技术栈规格说明

| 层次 | 选型技术 | 核心功用 |
| :--- | :--- | :--- |
| **前端展现层** | **React 18** + 原生微质感 CSS + **ECharts** + **NVL Canvas 知识图谱引擎** | 电脑手机双模自适应、5角色动态切换、60s 短信验证码倒计时、密码强度校验、PPG脉搏血氧蓝牙仿真流 |
| **后端服务层** | **Python 3.14 + Flask 3.0** + Flask-CORS + PyJWT | RESTful 规范 API、RBAC 细粒度角色鉴权、短信防刷限流、全链路操作审计 |
| **关系型数据库** | **MySQL 8.0** (库名: `respicare_db`) | 存储用户账号凭证、手机号、加盐哈希密码、患者档案、处方依从性、IoT 遥测时序、审计日志 |
| **图数据库引擎** | **Neo4j 5.x + APOC Core** (Bolt: 7687) | 存储 `Patient`、`Observation`（CAT/mMRC 打卡链）、`Exacerbation`（急性加重红色事件）、`Vaccination`（疫苗档案）及 COPD 临床本体 |
| **隐私脱敏中间件**| **Neo4j APOC 存储过程 (`apoc.create.vNode`)** | 绝不向前端暴露裸数据库连接，经后端网关生成 `COPDTrend` 脱敏虚拟节点，保护患者隐私 |

## 3. 五大角色专属工作台 (涵盖 46+ 核心业务模块)

### 3.1 患者端 (Patient) —— 10 大功能模块
- **[P01] 呼吸健康看板总览**：脉搏血氧、CAT 症状评分、mMRC 气促级别、吸入依从性与今日提醒。
- **[P02] 每日 CAT/mMRC 症状量表打卡**：8 道题目 0~5 分滑动选择，自动计算并写入图数据库时序链。
- **[P03] 急性加重红色事件紧急上报**：感冒/受凉等诱因标签勾选，一键直报随访医生李华山主任。
- **[P04] 身体变化趋势**：近 30/90 天 CAT 走势与血氧波动时序折线图，生成临床警示提示。
- **[P05] 肺康复知识图谱探索**：内嵌 NVL 力导向网络，探索疾病、症状、吸入剂与缩唇呼吸路径。
- **[P06] 吸入装置依从性打卡与用药闹钟**：都保/准纳尔用药计划打卡，含漱防感染提醒。
- **[P07] 疫苗接种档案追踪**：四价流感疫苗与23价肺炎球菌多糖疫苗有效期倒计时。
- **[P08] 智能设备蓝牙直连同步**：仿真连接便携脉搏血氧仪与便携肺功能仪，实时采集体征。
- **[P09] 在线复诊咨询与随访医生绑定**：绑定呼吸主任医师李华山，提供图文线上复诊。
- **[P10] 个人健康档案与脱敏导出**：生成 HIPAA/等保三级脱敏 JSON 健康报告卡。

### 3.2 医生端 (Doctor) —— 9 大临床模块
- **[D01] 患者图谱工作台**：调阅在管 280 位慢阻肺患者全病程临床图谱与用药网络。
- **[D02] GOLD E 组高危急性加重预警雷达**：多维雷达智能筛查频繁加重极高危患者。
- **[D03] 患者打卡历史与时序趋势回溯**：回溯纵向 CAT/mMRC 波动轨迹。
- **[D04] 急性加重临床复核与干预处置**：审核患者上报事件，开立抗生素与口服激素医嘱。
- **[D05] 吸入剂用药依从性评估与方案调整**：根据 MMAS 评分一键升级为三联强化制剂。
- **[D06] 临床 COPD 知识图谱检索**：推理药物配伍禁忌（如 β2 受体激动剂重叠慎用）。
- **[D07] 在线随访与图文问诊工作站**：处理线上患者求助，快速下发指导。
- **[D08] 疫苗接种指导建议签发**：秋季流感高发期前一键批量签发流感疫苗接种单。
- **[D09] 科研队列脱敏数据统计**：统计 128 例多中心队列 FEV1 改善率与依从性指标。

### 3.3 护士端 (Nurse) —— 9 大护理模块
- **[N01] 辖区/病区患者今日打卡监控台**：监控 36 位病区患者打卡状态，标记低氧警示。
- **[N02] 漏卡患者一键随访催办与脱落预警**：一键批量发送短信催办通知，防范脱落失访。
- **[N03] 急性加重应急接诊初筛**：快速评估口唇发绀与语言断续度，分级分流绿色通道。
- **[N04] 吸入装置实操视频与图谱宣教指引**：都保/准纳尔 5 步规范法操作与常见错误防范。
- **[N05] 疫苗接种预约与执行核销**：门诊流感疫苗核销登记与批号溯源。
- **[N06] 家用血氧/肺功能手工复核校验**：异常体征电话回访复测纠偏并入库。
- **[N07] 康复排痰操与呼吸训练指导**：吸呼比 1:2 缩唇呼吸训练交互节拍器。
- **[N08] 护理交接班记录与批注**：白班与晚夜班重点关注危重患者批注交接。
- **[N09] 随访问卷与宣教触达分发**：秋冬防寒保暖宣教资料全员推送。

### 3.4 院长端 (Director) —— 9 大管理驾驶舱模块
- **[M01] 全院慢病综合管理大屏**：展示在管总人数、打卡活跃率 (86.4%)、关键运营 KPI。
- **[M02] 急性加重发生率与再入院指标监控**：30 天再入院率 (4.8%) 与加重阻断数 (142次)。
- **[M03] 医护团队随访达标率与工作负荷排行**：科室主任与护士长管辖人数与达标榜单。
- **[M04] GOLD A/B/E 组人群分布演变分析**：E 组高危人群演化环形图与稳态转化分析。
- **[M05] 知识图谱临床规范路径质控分析**：规范吸入治疗质控达标率 (94.2%)。
- **[M06] 吸入剂全院使用依从性宏观分析**：都保/准纳尔/易纳器全院依从性大盘。
- **[M07] 疫苗预防接种覆盖率大盘**：流感疫苗覆盖率 (68.4%) 与肺炎疫苗覆盖率。
- **[M08] 医疗安全风险与合规预警拦截**：药物相互作用与不合理用药智能拦截雷达。
- **[M09] 经营与科研报表多维导出**：一键导出国家慢病达标统计表与科研数据集。

### 3.5 技术运维端 (Tech Admin) —— 9 大系统与工程模块
- **[T01] Neo4j 图数据库拓扑与 APOC 性能监控**：Bolt 连接池状态、QPS 与慢查询监控。
- **[T02] RBAC 用户角色与功能权限分配**：5 大角色 46+ 功能点矩阵式开关与授权。
- **[T03] 短信验证码服务商路由与黑名单网关**：阿里云与腾讯云短信通道熔断倒换、60s 频控。
- **[T04] IoT 医疗设备接入管道监控**：`apoc.load.json` 流式遥测吞吐量与设备在线探针。
- **[T05] 敏感数据脱敏规则与 vNode 虚拟节点配置**：`apoc.create.vNode(['COPDTrend'])` 策略。
- **[T06] 全链路访问审计日志与安全合规中心**：符合等保三级与 HIPAA 规范的访问日志。
- **[T07] 知识图谱 Schema 与本体字典维护**：Disease/Medication/Symptom 节点字典编辑。
- **[T08] 客户端版本灰度发布与配置热更新**：版本号控制与强制更新开关。
- **[T09] 关系库与图数据库双写一致性调度**：MySQL Binlog CDC 增量入图延时监控与补偿队列。

## 4. 快速启动与本地运行指南

### 方式一：一键双击启动 (标准 React 全栈)
直接在项目根目录下双击运行：
```text
启动智肺呼吸平台(React全栈).bat
```
脚本将自动：
1. 启动 Flask 后端 API (端口 5001)；
2. 启动 React 18 + Vite 前端工程 (端口 5173，自动代理 API 请求至 5001)；
3. 自动调起浏览器打开 `http://localhost:5173/`。

### 方式二：手动分步启动

#### 1. 启动 Flask 后端服务
```bash
cd backend
python app.py
```
> 后端服务将监听在 `http://localhost:5001`，健康检查接口：`http://localhost:5001/api/health`。

#### 2. 启动 React 18 + Vite 前端工程 (推荐)
```bash
cd frontend
npm run dev
```
> 在浏览器访问 `http://localhost:5173/`，支持 JSX 模块化与 HMR 热更新。

#### 3. (备用) 启动无编译轻量静态 Web
```bash
cd web
python -m http.server 8080
```
> 在浏览器访问 `http://localhost:8080/index.html`。
